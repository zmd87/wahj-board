# نموذج لوحة وهج

صفحة تقييم أسبوعية لفريق التحفيز في ثانوية ليلى الغفارية، تستخدمها رئيسات الأقسام لتقييم معلمات أقسامهن وإصدار تقرير PDF.

- `index.html` — الصفحة كاملة (المقدمة + نموذج التقييم + إصدار PDF).
- `vendor/jspdf.umd.min.js` — مكتبة jsPDF 2.5.1 (MIT) لإنشاء ملف PDF، مضمّنة محلياً لتعمل الصفحة دون الاعتماد على CDN.
- `assets/` — شعار الفريق وشعار المدرسة (انظري `assets/README.md`).

## مواعيد النموذج (توقيت الكويت UTC+3)
مفتوح من الأحد إلى الأربعاء طوال اليوم، ويوم الخميس حتى 10:29 صباحاً، ويُقفل من الخميس 10:30 صباحاً حتى نهاية السبت. تتحقق الصفحة من الموعد كل نصف دقيقة.

## النشر
صفحة ثابتة بلا خادم: يمكن نشرها عبر GitHub Pages (Settings → Pages → Deploy from branch) ومشاركة الرابط.
